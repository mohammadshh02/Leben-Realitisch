# Leben Realistisch

Ein Lebensplaner für Leute, die sich immer zu viel vornehmen.

Die App rechnet aus, wie viel Zeit du **wirklich** hast, und lässt dich nur so viel planen, wie realistisch reinpasst.

## So funktioniert's

1. **Meine Woche**: Trag ehrlich ein, wohin deine Zeit geht (Schlaf, Arbeit, Haushalt, Erholung …). Übrig bleibt deine freie Zeit.
2. **Umsetzungsquote**: Kein Mensch schafft 100 % von dem, was er plant. Die App rechnet am Anfang mit 60 %. Aus *freier Zeit × Quote* ergibt sich deine **realistische** Zeit für Ziele.
3. **Ziele**: Pro Ziel gibst du Stunden pro Woche und einen winzigen nächsten Schritt an. Passt ein Ziel nicht mehr rein oder hast du schon 3 aktive Ziele, landet es automatisch auf der **Später-Liste**. Gestrichen wird es dadurch nicht.
4. **Wochen-Check**: Einmal pro Woche trägst du ein, wie viele Stunden du tatsächlich investiert hast. Ab 2 Wochen rechnet die App mit deiner **echten** Quote (aus den letzten 4 Wochen). Dein Plan passt sich also dir an und nicht umgekehrt.

## Starten

Kein Build nötig. Einfach `index.html` im Browser öffnen.

Die Daten bleiben lokal in deinem Browser (localStorage). Unter *Wochen-Check → Daten sichern* kannst du sie als JSON exportieren und wieder importieren.
